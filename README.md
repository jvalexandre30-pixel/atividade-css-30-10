# 🌐 Meu Site — Projeto HTML e CSS

Olá! Seja bem-vindo(a) ao meu projeto! 😊

Este site foi desenvolvido como parte dos meus estudos em desenvolvimento web, com o objetivo de colocar em prática meus conhecimentos em **HTML5 e CSS3**, explorando a criação de páginas, organização de conteúdo e estilização de elementos.

A ideia foi construir um site simples, bonito, organizado e fácil de navegar, utilizando um menu lateral para acessar diferentes seções.

## ✨ Sobre o projeto

O projeto apresenta um site com identidade visual própria, contendo um menu de navegação lateral, imagem centralizada, cartões de conteúdo e uma área de contato.

Durante o desenvolvimento, procurei trabalhar a estrutura da página e a organização dos elementos, buscando deixar a experiência de navegação mais agradável.

## 🚀 Funcionalidades

O site conta com as seguintes seções:

- 🏠 **Início:** apresentação do site e seus objetivos.
- 👤 **Sobre:** informações sobre o projeto e sua missão.
- 🛠 **Serviços:** apresentação dos serviços oferecidos.
- 📁 **Projetos:** espaço para apresentar trabalhos e atividades.
- 📞 **Contato:** informações de contato e formulário para envio de mensagens.

Outros recursos presentes:

- Menu lateral com navegação entre as seções.
- Imagem centralizada no menu.
- Cartões para organizar os conteúdos.
- Formulário com campos de nome, e-mail e mensagem.
- Adaptação do layout para telas menores.

## 🛠 Tecnologias utilizadas

As tecnologias utilizadas neste projeto foram:

- **HTML5:** responsável pela estrutura e organização do conteúdo.
- **CSS3:** utilizado para cores, espaçamentos, posicionamento, efeitos e responsividade.
- **Visual Studio Code:** ambiente utilizado para escrever e editar os códigos.

## 💻 Como visualizar o projeto

Se quiser executar o projeto no seu computador, siga estes passos:

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Verifique se as pastas e os arquivos estão organizados corretamente.
4. Abra o arquivo `html/index.html` no navegador.
5. Navegue pelas seções utilizando o menu lateral.
